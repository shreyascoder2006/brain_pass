# Right Frontal Glioblastoma (High-Grade)

### Clinical Profile
- **Diagnosis**: Right Frontal Glioblastoma (High-Grade)
- **Location**: Right Frontal Lobe (+x, +y)
- **Summary**: Large aggressive high-grade glioma with thick nodular enhancing rim, central necrotic core, and extensive surrounding vasogenic edema with sulcal effacement.

### Tumor Volumes
- **Whole Tumor (WT)**: 50.46 mL
- **Tumor Core (TC)**: 20.35 mL
- **Enhancing Tumor (ET)**: 13.19 mL
- **Peritumoral Edema (ED)**: 30.11 mL
