# Bifrontal Butterfly Glioma (Corpus Callosum)

### Clinical Profile
- **Diagnosis**: Bifrontal Butterfly Glioma (Corpus Callosum)
- **Location**: Genu of Corpus Callosum / Bi-hemispheric (Midline)
- **Summary**: Trans-callosal lesion bridging across the midline into both frontal lobes with symmetric wing-like flair hyperintensity.

### Tumor Volumes
- **Whole Tumor (WT)**: 84.86 mL
- **Tumor Core (TC)**: 28.17 mL
- **Enhancing Tumor (ET)**: 23.34 mL
- **Peritumoral Edema (ED)**: 56.70 mL
