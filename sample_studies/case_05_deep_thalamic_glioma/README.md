# Deep Thalamic Centromedial Lesion

### Clinical Profile
- **Diagnosis**: Deep Thalamic Centromedial Lesion
- **Location**: Right Thalamus / Paraventricular (+x, -y, +z)
- **Summary**: Deep-seated subcortical lesion adjacent to the third ventricle with moderate mass effect on the right lateral ventricular frontal horn.

### Tumor Volumes
- **Whole Tumor (WT)**: 17.01 mL
- **Tumor Core (TC)**: 7.16 mL
- **Enhancing Tumor (ET)**: 5.74 mL
- **Peritumoral Edema (ED)**: 9.85 mL
