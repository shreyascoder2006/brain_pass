# Cerebellar Posterior Fossa Mass

### Clinical Profile
- **Diagnosis**: Cerebellar Posterior Fossa Mass
- **Location**: Right Cerebellar Hemisphere (+x, -y, -z)
- **Summary**: Infratentorial mass in the posterior fossa causing local compression of the fourth ventricle and surrounding cerebellar edema.

### Tumor Volumes
- **Whole Tumor (WT)**: 16.67 mL
- **Tumor Core (TC)**: 7.46 mL
- **Enhancing Tumor (ET)**: 6.29 mL
- **Peritumoral Edema (ED)**: 9.22 mL
