# Extensive Infiltrative Oligodendroglioma

### Clinical Profile
- **Diagnosis**: Extensive Infiltrative Oligodendroglioma
- **Location**: Right Fronto-Parietal Region (+x, +y, +z)
- **Summary**: Very large diffuse infiltrative mass spanning multiple lobes with massive T2/FLAIR abnormality and high whole-tumor to tumor-core volume ratio.

### Tumor Volumes
- **Whole Tumor (WT)**: 179.00 mL
- **Tumor Core (TC)**: 22.60 mL
- **Enhancing Tumor (ET)**: 19.77 mL
- **Peritumoral Edema (ED)**: 156.40 mL
