# Left Temporal Infiltrative Astrocytoma

### Clinical Profile
- **Diagnosis**: Left Temporal Infiltrative Astrocytoma
- **Location**: Left Temporal Lobe (-x, -y, -z)
- **Summary**: Predominantly infiltrative low-to-intermediate grade lesion with diffuse T2/FLAIR hyperintensity and subtle patchy enhancement.

### Tumor Volumes
- **Whole Tumor (WT)**: 35.44 mL
- **Tumor Core (TC)**: 7.68 mL
- **Enhancing Tumor (ET)**: 7.12 mL
